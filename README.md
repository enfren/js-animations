# JS Animations

Simple standalone Canvas animations. No dependencies.

| Demo | What it does |
| --- | --- |
| [Bouncing Ball](https://enfren.github.io/js-animations/bouncing-ball/) | Gravity + bounce with energy loss |
| [Mouse Trail](https://enfren.github.io/js-animations/mouse-trail/) | Colorful particles follow your cursor |

Each demo is a single `index.html` file. Just open it in a browser.
